# contrib-notes (personal / contributor onboarding)

This directory holds **informal onboarding notes** for people contributing to **kubernetes-sigs/cluster-api**. It is **not** part of the published Cluster API book and **not** an official Kubernetes SIG document.

- **Languages:** English with optional **Hinglish** asides in some pages.
- **Official docs:** [cluster-api.sigs.k8s.io](https://cluster-api.sigs.k8s.io) and the repo [`docs/book/src/`](../docs/book/src/) tree.
- **Contributing rules:** [`CONTRIBUTING.md`](../CONTRIBUTING.md) at repo root.

## Contents

| Path | Purpose |
|------|---------|
| [`INDEX.md`](INDEX.md) | **Start here** — master index + links to every walkthrough |
| [`book-hinglish/`](book-hinglish/) | **Same folder layout as `docs/book/src/`** — Hinglish/simple companion for every book page ([`src/SUMMARY.md`](book-hinglish/src/SUMMARY.md)) |
| [`onboarding/`](onboarding/) | First-time contributor guide, repository map / deep dive, glossary |
| [`code-walkthrough/`](code-walkthrough/) | How major packages fit together (incremental, code-backed) |

## Git

You may commit this folder to **your fork** only, or add `contrib-notes/` to `.gitignore` if you want it strictly local—your choice.
